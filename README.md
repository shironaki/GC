# Gangstar City: Revival

Мобильная браузерная игра в духе оригинальной Gangstar City. Игровой мир и персонажи рисуются процедурно через Canvas 2D; внешние изображения и спрайты не используются. Интерфейс рассчитан прежде всего на Android Chrome.

## Играть

После публикации GitHub Pages: **https://shironaki.github.io/GC/**

В Chrome можно выбрать «Добавить на главный экран». PWA-оболочка и офлайн-кэш работают через HTTPS. Первый запуск должен быть онлайн, чтобы браузер загрузил и закэшировал файлы игры.

## Управление

- Виртуальный джойстик — движение и управление машиной.
- **БЕГ** — ускорение пешком с расходом выносливости; отпусти кнопку, чтобы восстановить её.
- **ДЕЙСТВИЕ** — взаимодействие с объектами, посадка/выход из автомобиля, покупка бизнеса.
- **АТАКА** — ближний бой или выстрел из экипированного пистолета.
- Кнопка меню — бизнесы, команда, аптечки, инвентарь, следующий игровой день, сохранение.
- На клавиатуре: WASD/стрелки — движение, E — действие, Space — атака, Esc — закрыть окно.

## Игровые системы

- Три района города с постепенным открытием.
- Изометрический процедурный город, дороги, здания, декорации и мини-карта.
- Пешеходы, банды, полиция, нанимаемые бойцы-компаньоны и шкала розыска.
- Автомобили: вход, управление, выход и ремонт.
- Ближний бой, стрельба, патроны, здоровье, выносливость и аптечки.
- Сюжетная цепочка заданий, деньги, репутация и награды.
- Покупка и улучшение объектов с пассивным доходом.
- Локальное сохранение прогресса в браузере.
- PWA-манифест, иконка и service worker для офлайн-оболочки.

## Проверка проекта

Требуется Node.js 22+.

```bash
npm install
npx playwright install chromium
npm test
```

CI запускает проверку синтаксиса, smoke-тест структуры и Chromium-проверку мобильного сценария: запуск Canvas, отрисовка мини-карты, открытие меню, работа с аптечками, клавиатурное движение и сенсорная кнопка атаки.

## Сохранения

Прогресс хранится локально в браузере. Очистка данных сайта удалит сохранение. Кнопка «Сохранить игру» записывает прогресс немедленно; также игра периодически сохраняется автоматически.

## Статус

Текущая версия — **release candidate для первого полноценного пользовательского прогона**, а не заявление о завершённой коммерческой игре. Автоматические браузерные проверки подтверждают только те сценарии, которые реально проходят в CI. Отдельно необходима проверка на физическом Android-устройстве: производительность, сенсорное управление, установка PWA, обновление service worker, сохранение после перезапуска Chrome и полный проход сюжетной цепочки.

Не заявляются как реализованные: мультиплеер, облачные сохранения, полноценные интерьеры, озвучка/музыка, сложная дорожная симуляция и полноценная система поведения союзников. Эти функции не должны выдаваться за готовые.
